# Project screenshots

Capture the running dashboard here so the portfolio image shows the real app:

1. Start the API and Streamlit dashboard using the commands in the root README.
2. Turn on **Simulation mode**, choose **Get weather**, and wait for charts to render.
3. Capture the dashboard with the location, risk notifications, charts, and map visible.
4. Save it as `dashboard-overview.png` and add `![Dashboard overview](images/dashboard-overview.png)` to the root README.

Simulation makes the screenshot repeatable and clearly labels the example data.
